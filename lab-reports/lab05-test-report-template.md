## 1. Загальна інформація

### 1.1 Мета тестування
Перевірка функціональності REST API інтернет-магазину кросівок, включаючи:
- CRUD операції з товарами
- Отримання категорій
- Відправка відгуків
- Валідація даних
- Обробка помилок

### 1.2 Тестове середовище
- **Сервер:** http://localhost:5000
- **Інструмент:** Postman
- **База даних:** SQLite (db.sqlite)
- **Документація:** Swagger UI (http://localhost:5000/apidocs)

---

## 2. Endpoints для тестування

| Метод | Endpoint | Опис |
|-------|----------|------|
| GET | `/api/v1/products` | Отримати список товарів |
| GET | `/api/v1/products/<id>` | Отримати товар за ID |
| POST | `/api/v1/products` | Створити новий товар |
| DELETE | `/api/v1/products/<id>` | Видалити товар |
| GET | `/api/v1/categories` | Отримати список категорій |
| POST | `/api/v1/feedback` | Надіслати відгук |
| POST | `/api/v2/products` | Створити товар (v2, строга валідація) |

## 5. Виявлені проблеми

### 5.1 Критичні проблеми
```
Критичних проблем не виявлено. API працює стабільно.
```

### 5.2 Некритичні проблеми
```
1. Паролі зберігаються у відкритому вигляді (рекомендується додати хешування)
2. Відсутня пагінація для великих списків товарів
3. Немає обмеження на розмір запитів
```

### 5.3 Пропозиції щодо покращення
```
1. Додати JWT авторизацію для захищених endpoints
2. Реалізувати хешування паролів (bcrypt/werkzeug.security)
3. Додати rate limiting для запобігання зловживань
4. Реалізувати пагінацію (limit/offset параметри)
5. Додати логування запитів для моніторингу
6. Розширити валідацію (email format, password strength)
```
